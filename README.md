
# Reconnaissance and SQL Injection

## Project Overview
This mini project focuses on understanding web application reconnaissance and identifying potential SQL injection weaknesses in an authorized testing environment.

## Objectives
- Understand the basics of web application reconnaissance.
- Identify information exposed by a web application.
- Understand how SQL injection works.
- Observe how improper input handling can produce database errors.
- Learn basic methods to prevent SQL injection.

## Tools and Environment
- Kali Linux
- bWAPP (Buggy Web Application)
- Docker
- Web Browser
- Gobuster
- Burp Suite (where applicable)

## Methodology
1. Set up the vulnerable bWAPP application in a local Docker environment.
2. Access the application through a web browser.
3. Perform basic reconnaissance of the application.
4. Explore the SQL injection testing functionality.
5. Observe application responses to test inputs.
6. Document findings and possible security improvements.

## Key Learning Outcomes
- Understood the purpose of reconnaissance in web security.
- Learned how to access and test a vulnerable web application in a local lab.
- Observed how unusual input can trigger database error messages.
- Understood why input validation and parameterized queries are important.

## Security Note
All testing was performed in a controlled local lab environment for educational purposes. No unauthorized systems were tested.
