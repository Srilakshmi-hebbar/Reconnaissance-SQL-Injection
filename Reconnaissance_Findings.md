
# Reconnaissance Findings

## 1. Introduction
Reconnaissance is the initial phase of a security assessment. It involves collecting information about a target application to understand its structure and identify areas that may require further testing.

## 2. Testing Environment
- Operating System: Kali Linux
- Application: bWAPP
- Environment: Local Docker lab

## 3. Activities Performed
- Accessed the bWAPP application in the local lab.
- Explored the application's available pages and functionality.
- Observed application responses during testing.
- Used reconnaissance concepts to understand the application's exposed information.

## 4. Observations
The local application was accessible through the browser. Its pages and available features provided an opportunity to understand how a web application can be examined before security testing.

## 5. Security Considerations
Reconnaissance findings should be documented carefully. Information collected during this phase can help determine which areas need further security assessment.

## 6. Conclusion
This activity helped me understand the importance of reconnaissance in web application security testing and how it supports the later stages of a security assessment.

**Note:** Only observations actually verified in the lab should be treated as confirmed findings.
