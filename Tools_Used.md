
# Tools Used

The following tools and technologies were used or studied as part of this mini project.

## 1. Kali Linux
A Linux distribution commonly used for cybersecurity testing and security assessments.

## 2. bWAPP
A deliberately vulnerable web application used to understand and practice web application security testing.

## 3. Docker
Used to run the bWAPP application in a local lab environment.

## 4. Gobuster
A directory and file discovery tool used during web reconnaissance.

## 5. Web Browser
Used to access the local application and observe its responses.

## 6. Burp Suite
A web security testing tool useful for inspecting and analyzing HTTP requests and responses.

## Note
Tools listed here describe the project environment and learning activities. Only tools actually used for a particular test should be reported as having performed that test.
