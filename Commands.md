
# Commands Used

This file contains examples of commands relevant to the local reconnaissance and testing environment.

## 1. Check IP Configuration
```bash
ip a
```

## 2. Check Network Routes
```bash
ip route
```

## 3. Check Docker Containers
```bash
docker ps
```

## 4. Check Docker Images
```bash
docker images
```

## 5. Check Nmap Availability
```bash
nmap --version
```

## 6. Check Gobuster Availability
```bash
gobuster version
```

## 7. Basic Nmap Scan
```bash
nmap -sV <authorized-target>
```

Replace `<authorized-target>` with the IP address or hostname of a system you are authorized to test.
